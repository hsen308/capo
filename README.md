# CAPO Production

[Live website](https://capo-dun.vercel.app)

Editorial portfolio for a Beirut photography and film studio covering weddings, proposals, and personal milestones.

![CAPO Production website preview](https://raw.githubusercontent.com/hsen308/hsen308/main/assets/projects/capo.webp)

## My role

I designed and developed the website through Novu Studios, translating a visual-production brand into a responsive, image-led experience.

## Highlights

- Editorial art direction and typography
- Light and dark theme support
- Responsive image-led layouts
- Social preview metadata
- Accessible reduced-motion-friendly behavior

## Stack

HTML · CSS · JavaScript · Responsive design · Vercel

## Run locally

Open `index.html` directly or serve the folder with:

```bash
python -m http.server 8000
```
